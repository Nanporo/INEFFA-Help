使用方式

STEP 01

選擇正確頻道

請使用 SignalTest 頻道，或直接對 INEFFA 發起私訊：

  • ✅ 私訊 DM (直接對話)
  • ❌ 頻道 0 (Primary) 禁行
  • ❌ 頻道 1 (MeshTW) 禁行
  • ✅ 頻道 2 (SignalTest)
  • ❌ 頻道 3 (Emergency!) 禁行
STEP 02

發送前綴與指令

在公開頻道呼叫需加入觸發前綴，在點對點私訊則可不加上前綴：

公開頻道：
@inf loc XQ10 或 @ine node

私訊 (DM)：
time 或 help

STEP 03

接收即時回應

機器人將在數秒內回傳資料，並支援快捷機制：

預設回覆：
發送 @inf 回覆通聯確認與台詞；發送 @inf node 查自身節點。

表情反應：
發送 test 回覆 ✅，發送 newbie 回覆 👋。

注意事項

嚴禁於非測試頻道濫發

請勿在非測試頻道呼叫機器人。若嘗試呼叫系統會在首次發出警示提醒，隨後將進入靜音模式直接忽略。

冷卻與特定節點保護

為避免連續使用佔據頻寬，同一發送者連續呼叫設有冷卻保護。
請維持至少 5~10 秒間隔，切勿高頻發送相同指令。

設計上已排除其它常見機器人（如 ARBot、MeshAI 天台、番仔園等），並且已直接排除 ID 開頭為 !abcd 的 TWMQTT 虛擬垃圾節點。

訊息長度省略

若節點長名稱（longName）過長，將自動以省略號（...）精簡以防發送失敗。

重複名稱請改用 8 碼 ID

當輸入名稱搜尋到多筆節點時，機器人將回覆 [INEFFA] 找到多筆結果，請改用ID查詢。此時請直接輸入該節點的末 4 碼或完整 8 碼 Node ID（例如 @inf 28eae397）即可查詢。
